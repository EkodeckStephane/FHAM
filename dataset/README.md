# Experimental image corpus

This directory contains the exact 512 x 512 grayscale PNG files consumed by
the FHAM experiments.

- `controlled/`: eight standard scikit-image reference images.
- `stress/`: 19 scikit-image reference images plus 200 face photographs from
  the scikit-image LFW subset, for 219 images in total.

The images are not generated by FHAM or by a generative model. Most are
photographs or scientific images. The stress corpus also deliberately contains
non-photographic reference cases: the `horse` binary silhouette, the
`colorwheel` synthetic graphic, the scikit-image `logo`, and scanned document
images. Each subset has a `manifest.csv` recording source, content type,
dimensions, and preprocessing.

The pipeline regenerates these files from the installed `scikit-image` package.
Consult the scikit-image data documentation and the Labeled Faces in the Wild
project for the original dataset provenance and applicable terms.
